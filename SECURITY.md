# Security Policy

## Supported versions

Security fixes are provided for the latest published ThreatBrief release.
Users should update to the newest release before reporting an issue that may
already have been corrected.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature on the repository's
Security tab. This creates a private report visible to the maintainers.

Do not open a public issue for suspected vulnerabilities, exposed credentials,
or reports containing sensitive threat-intelligence data. Include reproduction
steps, affected versions, impact, and any suggested mitigation. Maintainers
will acknowledge a report as soon as practical and coordinate disclosure after
a fix is available.

ThreatBrief is a defensive intelligence tool. Reports involving attempts to
make it execute untrusted feed content or disclose locally stored API keys are
especially welcome.
